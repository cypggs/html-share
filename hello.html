Hello HTML Share

这是一个示例页面，展示了 html-share 的页面模板和样式一致性。你可以复制 template.html 来创建自己的分享页。

2026-10-12 示例 模板

快速开始

1. 复制 template.html 为一个新文件，比如 my-share.html。

2. 修改文件里的 <title>、<meta name="description">、<meta name="date"> 和 <meta name="tags">。

3. 把正文内容放进 <article class="content"> 里。

4. 推送后 GitHub Actions 会自动更新首页卡片。

示例代码块

<meta name="tags" content="示例, 模板">

样式说明

  • 所有页面共享深色玻璃拟态风格。
  • 导航栏返回首页，保持站点一致性。
  • 卡片和正文区域自动适配移动端。
